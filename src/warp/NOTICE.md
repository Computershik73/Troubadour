# Обход блокировок: код Dante-WARP

Всё в этой папке, кроме `DebugLog.m`, `YTWarp.*` и `YTTunnelProtocol.*`,
взято из Dante-WARP.

- Автор: https://github.com/qwertyu1opz — код передан владельцу Troubadour
  с разрешением использовать при условии, что имя автора стоит в разделе,
  где включается обход (так и сделано: «Настройки → Обход блокировок»).
- `monocypher.c`, `monocypher.h` — Monocypher, © 2017–2020 Loup Vaillant,
  BSD-2-Clause или CC0-1.0 на выбор (уведомление — в самих файлах).

Что изменено против исходника (каждое место помечено «Troubadour:»):

- `AWGTunnel.m` — приёмник говорит только на SOCKS5; ветка, отдававшая
  прочих клиентов HTTP-прокси системной службы, заменена закрытием.
  Размер пакета в туннеле по умолчанию 1280 (у автора 1400): с 1400
  полноразмерные сегменты сервера в туннель WARP не влезали и пропадали.
- `AWGIPStack.m` — входящий пакет обрезается по длине из заголовка IP
  (WireGuard вправе дополнить его нулями).
- `AWGWarpRegistrar.m` — убран путь регистрации через внешнюю программу
  `/usr/bin/vless-core-curl` (и `posix_spawn` вместе с ним).
- `AmneziaWGManager.*` — нет самопроизвольного подключения при первом
  обращении; подключением ведает `YTWarp`. Новая личность WARP
  подключается через точку входа несущего, до которой рукопожатие уже
  дошло (`provenEndpoint`), а не через адрес из ответа Cloudflare: тот
  приходил вне диапазонов WARP (104.16.x) и в сети с ТСПУ молчал.
- `DanteFixer.m` — своя личность, не ответившая на своей точке, пробуется
  через точку несущего; после первого рабочего несущего сиды больше
  не перебираются (отвечали на рукопожатие, но не пропускали данных);
  неподключившаяся свежая личность не сохраняется; номер в «WARP n/5» —
  номер попытки.
- `DanteNetworkProbe.m` — убран импорт заголовка службы; определение
  текущей сети переписано через `getifaddrs` (у автора оно было в службе).
- `TLSTrustManager.m` — `NSURLCredential` ищется по имени: прямая ссылка
  привязывала приложение к CFNetwork, и на части iOS оно не запускалось.
- `DebugLog.m` — свой: пишет в общий журнал приложения через NSLog.

Не взяты: вся папка `Daemon/` (служба, utun, перенаправление pf,
системный прокси, HTTP-прокси, сканер), `DanteCompat.h`.

Проверка сертификата в `TLSTrustManager` (регистрация WARP) оставлена
как у автора — по решению владельца проекта: итог проверки пишется
в журнал, но соединение принимается всегда.
